## 3. Student- & Intern-Specific Platforms + Curated GitHub Lists

This family is where student-*exclusive* supply lives: postings an employer sends only to campus systems (Handshake, Symplicity CSM, 12twenty) never appear on Indeed or in an ATS crawl, and non-tech employers — hospitals, insurers, utilities, state agencies, ag-science firms, defense primes — post their one technical intern req to a school portal and nowhere else. That is exactly the "technical role at a non-tech company" gap. The effort profile splits sharply: the curated GitHub lists are the single best yield-per-line-of-code source in the entire catalog (open JSON, no auth, no anti-bot, daily refresh, already deduped and normalized), while the campus platforms are auth-walled, per-school, and mostly require a logged-in session or a headless browser. Build GitHub first (a weekend), then Handshake-with-session (a week), then everything else opportunistically. Note the calendar: today is Aug 2026, which means the **Summer 2027** cycle is the live season and the community repos have already been renamed to `*2027*`.

**Ingestion notes**

*Hardcode these exact templates.* The four highest-value endpoints in this section, all unauthenticated:

```
https://raw.githubusercontent.com/SimplifyJobs/Summer2027-Internships/dev/.github/scripts/listings.json
https://raw.githubusercontent.com/SimplifyJobs/New-Grad-Positions/dev/.github/scripts/listings.json
https://raw.githubusercontent.com/vanshb03/Summer2027-Internships/dev/.github/scripts/listings.json
https://www.levels.fyi/js/internshipData.json          # requires --compressed / gzip Accept-Encoding
```

Plus the season-agnostic discovery templates:

```
https://raw.githubusercontent.com/{owner}/{repo}/{branch}/.github/scripts/listings.json   # Simplify schema family
https://raw.githubusercontent.com/{owner}/{repo}/{branch}/data/listings.json              # dreamworkhq / workopia family
https://raw.githubusercontent.com/{owner}/{repo}/{branch}/data/active.json                # workopia
https://github.com/{owner}/{repo}/commits/{branch}.atom                                   # change detection
https://api.github.com/users/{org}/repos?per_page=100&sort=pushed                         # vendor-family enumeration
https://api.github.com/search/repositories?q=Summer{YEAR}+Internships+in:name             # next-season discovery
https://unstop.com/api/public/opportunity/search-result?opportunity=internships&page={N}  # open JSON, no key
https://app.joinhandshake.com/stu/postings?page={N}&per_page=100                          # JSON, needs session cookie
https://{school}.joinhandshake.com/login                                                  # cookie minting
https://{school}.12twenty.com/Login
https://{school}-csm.symplicity.com/students/
https://app.ripplematch.com/v2/public/company/{slug}
```

*Branch names are a real footgun.* SimplifyJobs and vanshb03 use `dev`; speedyapply, zapplyjobs, dreamworkhq, workopia, zshah101 use `main`; jobright-ai and deepanshu1422 use `master`. Always resolve `default_branch` from `GET /repos/{owner}/{repo}` rather than guessing.

*Rate limits.* GitHub REST unauthenticated is **60 req/hr** — verified in this session; with a PAT it is 5,000/hr core and 30/min for search. `raw.githubusercontent.com` is a separate CDN with generous limits and is where all bulk fetching should go. Atom feeds are effectively unlimited. Prefer the atom-feed-then-fetch pattern: polling a 12 MB JSON hourly for 5 repos is ~1.4 GB/day of pointless transfer; polling the atom feed first cuts that by ~99%.

*Anti-bot posture, by tier.* Everything on GitHub and `levels.fyi` is wide open. `unstop.com`'s public API is open. Handshake returns clean JSON errors rather than blocking, but its SPA path (`/job-search`) 403s bare clients and its ToS prohibits scraping — use your own session, low volume, and treat it as a personal-use fetch. Cloudflare/bot-wall confirmed on: `gradcracker.com` (403), `brightnetwork.co.uk` (403), `internships.com` (403 on `/internships` and `/sitemap.xml`), `12twenty.com` tenant logins (403), `jobs.vault.com` (403), `gradaustralia.com.au` (202 challenge), `riipen.com` app (202). All of those need a real browser UA at minimum, headless for the JS-gated ones. Symplicity CSM is server-rendered and CSRF-protected but not bot-walled — a requests session with cookie + token works.

*Schema normalization.* The Simplify schema (`company_name`, `title`, `url`, `locations[]`, `terms[]`, `date_posted` unix, `active`, `is_visible`, `sponsorship`, `degrees[]`) is the de-facto standard — three of the four canonical repos plus several clones emit it. Normalize everything else *into* it. Two filters matter and are easy to get wrong: keep only `active == true AND is_visible == true` (inactive rows are retained in the file indefinitely — the 14,647-record Simplify file includes long-dead Spring 2026 reqs), and match `terms[]` against the season you want rather than trusting the repo name. Dedup across repos on normalized `(company_name, title, first-location)` plus the ATS job id parsed out of `url` — the same req appears in Simplify, vanshb03, speedyapply, and jobright with four different tracking wrappers, so **always resolve the final URL** before hashing.

*Seasonal calendar for this family.* **Late Jul–Aug**: community repos are renamed/rebuilt for the next cycle (verified — Simplify was already `Summer2027` and had pushed within the hour on 2026-08-01); off-season repos for Fall appear; underclassmen programs (Google STEP, Microsoft Explore, NVIDIA Ignite) open. **Aug–Sep**: quant and top-tier tech open first and close in days; Handshake career-fair rosters publish; campus CSM postings surge as employers set fall recruiting. **Sep–Nov**: peak volume for both internships and new-grad; AI residencies close. **Dec–Feb**: research/REU deadlines (the `Research-Internships-for-Undergraduates` list matters most here); open-source programs (GSoC applications ~Mar, Outreachy Feb) open. **Jan–Apr**: the long tail — mid-market and non-tech companies post, which is exactly the segment this student wants and the segment the big lists cover worst; campus portals and Parker Dewey carry it. **Feb–Apr**: Australian (GradConnection) cycle opens for the Nov–Feb southern-hemisphere summer. Forage and Parker Dewey are the only truly aseasonal rows here — run them continuously.

*Historical data is free and worth taking.* `vanshb03/.../archived/2026/archived.json` (1.18 MB), `archived/2025/archived.json` (2.40 MB), `workopia/.../README-Inactive.md` (976 KB), and `zshah101/.../data/known_windows.json` collectively let you build a per-company "when does their window open" predictor without any scraping of your own.

**Traps & dead ends**

- **The GitHub API 404s on renamed orgs.** `cvrve/Summer2026-Internships` returns a clean 404 from `api.github.com`, which looks like "repo deleted." It is not — the *browser* URL 301s to `vanshb03/Summer2027-Internships`. Resolve renames via `curl -IL https://github.com/...`, never via the REST API. Same story for `Ouckah/*`, `coderQuad/*`, `pittcsc/Summer2024-*`.
- **Hardcoding the year in a repo path works, but hardcoding the *branch* does not.** Old paths redirect forever; a `main` branch on a `dev`-default repo just 404s.
- **`LorenzoLaCorte/european-tech-internships-2026`'s README is a decoy** — 5 KB of boilerplate. The data is in `scraped/internships_table.md`. Several repos in this family put data outside the README; always list the tree before assuming.
- **speedyapply ships no JSON.** Its `.github/scripts/` contains only `package.json`/`tsconfig.json`; the postings live in a private Supabase and only reach you as rendered markdown. Don't hunt for a `listings.json` there.
- **`app.joinhandshake.com/graphql` does not exist** (verified 404). Blog posts and old scrapers referencing a Handshake GraphQL API are wrong or describe an unrelated third-party project (`acs12/Handshake-GraphQL` is a student clone, not Handshake).
- **The Handshake EDU API is not available to students.** It is granted by a Relationship Manager to career-services *staff*. Every "Handshake API" search result leads here; it is a dead end unless a career-center sponsor requests access on the student's behalf.
- **Branded school portals ("Hire A Longhorn", "CareerConnect", "{Mascot}Link") are almost never distinct systems.** They are skins over Handshake, Symplicity CSM, or 12twenty. Building a per-school scraper is wasted work; resolve the vendor and reuse one of three adapters.
- **`intern.supply` and `youtern.com` no longer resolve** (DNS failure). `jumpstart.me` no longer resolves — Jumpstart is now Untapped. `myinterfase.com` no longer resolves.
- **Chegg's Internships.com is dead** (closed Dec 2023, along with CareerMatch). The *current* `internships.com` is a different, reborn property under new ownership — do not treat old scrapers or old schema assumptions as valid.
- **`lodthe/awesome-internships` is GitHub-archived** (verified `archived: true`, frozen Dec 2024). `AlanChen4/Summer-2024-SWE-Internships` and `AlanChen4/2024-SWE-New-Grad` are also archived. `upupming/new-grad-positions` (2023), `mrhakimov/russian-internships` (2024), `ReaVNaiL/New-Grad-2024` (Nov 2024), `bsovs/Fall2025-Internships` (May 2025), `jobright-ai/2026-Internship` (Aug 2024) are all stale-but-not-archived, which is worse — they look live in search results and silently serve last season's data. Gate every repo on `pushed_at` within 14 days before trusting it.
- **Star count is a bad freshness proxy for bot repos.** `zapplyjobs/Canada-Internships-2027` has 0 stars and was pushed today; `Zackhardtoname/internships` has 952 stars and is ten months stale. Sort by `pushed_at`, not `stargazers_count`.
- **RippleMatch's student view is a biased sample, not a corpus.** You only see roles the matching algorithm assigns you. Two accounts with different profiles see different job sets — so a single-account scrape systematically under-counts. The `v2/public/company/{slug}` pages are the unbiased surface.
- **Vendor-published GitHub lists wrap every link in tracking parameters** (`?utm_campaign=...&utm_source=git` on jobright, redirector domains on zapplyjobs/Simplify). Store the resolved final URL or your dedup will fail and your click-through will 404 when the vendor rotates redirectors.
- **Symba, Yello, vFairs, Brazen, and Premier Virtual are employer-side SaaS, not sources.** They host events/programs; they publish no browsable index of student-facing postings. Only CareerEco and Career Fair Plus among the event platforms have a public, crawlable index.
- **Virtual Internships, Praxis, and Absolute Internship are pay-to-participate**, not competitive hires. Flag them clearly; a student with a normal CS résumé should not be paying for placement.
- **Do not scrape Simplify.jobs, Jobright.ai, or speedyapply.com directly** when their own GitHub mirrors give you the same rows for free with no anti-bot and an explicit invitation to consume. Scraping the site is strictly more work, more fragile, and more legally exposed for identical data.
- **Handshake's `robots.txt` blocks a long list of AI/scraper user agents** (AI2Bot, Bytespider, Diffbot, PetalBot, etc. via Vercel's recommended list). Your fetcher's UA matters; and the marketing site being crawlable says nothing about `app.joinhandshake.com`, which is a different posture entirely.
